# Вывеска — сайт студии

Статический сайт (HTML/CSS/JS) + один PHP-скрипт для приёма анкет из бота «Подбор сайта».

## Перед публикацией заменить заглушки
- `USERNAME` — ник в Telegram (в `index.html` и `brief.js`)
- `EMAIL` — рабочая почта (в `index.html` и `politika.html`)
- `[ФИО]`, `[ИНН]`, `[ДАТА]` — в `politika.html`

## Подключение Telegram-бота для анкет
1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → скопируйте **токен**.
2. Откройте своего бота и нажмите **Start**.
3. Узнайте свой `chat_id`: откройте в браузере
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — число в `"chat":{"id": ...}`.
4. На сервере скопируйте `api/config.example.php` в `api/config.php` и впишите токен и `chat_id`.
5. Пройдите анкету на сайте — сообщение должно прийти в бота.

Анкеты дополнительно сохраняются на сервере в `api/data/briefs-ГГГГ-ММ.log` (папка закрыта от браузера).

## Хостинг
Подходит любой хостинг с PHP 7.4+ и curl (например, Beget). Если сайт открыт с диска или сервер недоступен,
бот предлагает скопировать анкету и отправить её в Telegram вручную.
