# «Ганаш» — пример сайта-визитки (тариф «Визитка»)

Вымышленная кондитерская: торты на заказ, Санкт-Петербург. Одна страница, шесть блоков:
Торт по прокрутке → Работы → Начинки и цены → О кондитере → Как заказать → Контакты (карта и мессенджеры).

Статический сайт без сборки: HTML + CSS + JS. Открывается и с диска, и с любого хостинга.

## Структура
- `index.html` — вся страница, тексты, цены, SEO (title, description, Open Graph, schema.org `Bakery`).
- `css/style.css` — стили. Цвета в начале файла (`--cocoa-*`, `--cream-*`, `--gold`).
- `seq/desk/`, `seq/mob/` — 300 кадров первого экрана (WebP), отрисованы в Blender: торт вращается, на боку пишется
  «Торты на заказ», нож отрезает кусок, кусок выплывает, ягоды разлетаются в невесомости. `desk` — 1600×900, `mob` — 720×1280 (≈15 и ≈9 МБ: кадры лёгкие, плеер грузит их «от грубого к точному» и смешивает соседние, так что прокрутка плавная задолго до полной загрузки).
- `js/seq-player.js` — проигрыватель кадров на canvas: прокрутка → номер кадра, загрузка от грубого к точному.
- `js/seq-data.js` — сгенерирован из сцены: раскадровка и экранные точки для подписей слоёв (не править руками).
- `js/main.js` — шапка, меню, появление блоков, подписи слоёв на срезе, демо-окно.
- `fonts/` — Cormorant Garamond и Manrope (SIL OFL), свои файлы, без Google Fonts.
- `img/` — фото в WebP, `og.jpg` (превью ссылки). Без JavaScript первый экран показывает первый кадр.

## Демо-режим
У `<body data-demo>` кнопки Telegram, WhatsApp и телефона не ведут в чужие аккаунты: открывается окно
«Это пример сайта студии «Вывеска»» со ссылкой на студию. Для настоящего клиента:
1. убрать `data-demo` у `<body>`;
2. вписать ссылки: `https://t.me/<ник>`, `https://wa.me/<номер>`, `tel:+7...`;
3. удалить блок `<div class="demo" ...>` в конце `index.html` и строку «Пример сайта-визитки» в подвале.

Ссылка «Хочу такой сайт» ведёт на `../vyveska/index.html#tiers`. После публикации студии заменить на её адрес.

## Сцена торта (Blender)
Исходники — `3d/ganash-cake/` в корне проекта: `build.py` собирает сцену (торт, крошка, свет, стол), `anim.py` — анимация,
`knife.py`, `berries.py` — модели ножа и ягод. Перерисовать кадры:
1. `blender -b --factory-startup -P build.py` → `cake.blend` и `timeline.json`;
2. `blender -b -P render_frames.py -- --cam desk --frames 1-300 --stretch 300 --res 100 --samples 96 --motion-blur 1 --outdir OUT` (и `--cam mob`);
3. `python encode_seq.py OUT seq/desk 1600 900 64 desk_` (для `mob` — 720 1280, качество 66);
4. `python export_site_data.py 300` → `js/seq-data.js` (история сцены — 200 кадров, картинок — 300: `--stretch` растягивает её для плавности).
